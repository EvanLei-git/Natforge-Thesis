Service Host

Expose any local server to the internet through one tunnel - game servers (Minecraft, Terraria, GTA-MTA, …), websites, APIs, SSH, anything that listens on a TCP port. HTTP/HTTPS routes are reached by your subdomain; raw-TCP routes get a dedicated public port.

Getting started
  1. Request a tunnel - pick a subdomain (or leave it blank for a random one) and add a route per local port. Choose the route type: http/https for websites/APIs (reached at name.natforge.com), tcp/udp for game and other raw servers (reached at natforge.com:port).
  2. Run the agent on the machine hosting your server using the printed command (no port-forwarding needed).
  3. Share the address shown for each route - name.natforge.com for a website, or name.natforge.com:port for a game server. That name points at the NatForge server (not your own IP), which relays to your machine.

Tip: tcp and udp both get a dedicated public port, so UDP games (e.g. Valheim, Palworld) work too.
