Network administration

Monitor the network and enforce abuse controls. Blocked regions are applied by the control plane and propagated to the data plane.

Geographic / region blocking

Connections whose source IP geolocates (MaxMind GeoLite2) to a blocked country are refused platform-wide: the control plane rejects login/registration, and the data plane drops public tunnel connections. Tunnel owners can add their own per-tunnel country blocks on top of this.

Regions (data-plane nodes)

Each region is a data-plane VM running natforge-node. A node self-registers on boot with its own wildcard host + public TCP port pool; rename it, set a human region label, toggle whether users may place new tunnels there, or remove a decommissioned node. To add a region (e.g. a VM in Bulgaria), deploy a core there with a unique NODE_ID, a PUBLIC_HOST like bg.natforge.com, a reachable CONTROL_ENDPOINT / INTERNAL_URL, and point WEBSITE_URL here - it appears below automatically.
